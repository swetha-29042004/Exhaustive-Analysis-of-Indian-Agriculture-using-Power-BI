# Exhaustive-Analysis-of-Indian-Agriculture-using-Power-BI


## 🧩 Overview

This project demonstrates a three-week learning and implementation journey using **Microsoft Power BI**. It covers loading, cleaning, transforming, and visualizing data using two datasets — *Exhaustive Analysis of Indian Agriculture* and *Super Store Sales Data*. The goal is to build analytical dashboards that extract meaningful business insights.

---

## 📅 Week 1 – Exhaustive Analysis of Indian Agriculture

**Objective:**

To analyze Indian agriculture data and understand patterns using Power BI.

**Process:** 

Imported the dataset (CSV format), cleaned and transformed it in Power Query Editor by removing nulls and blank columns, checked data quality, and applied transformations.

**Outcome:**

Built a structured and clean dataset, created initial tables and visuals to explore agricultural trends, and designed a simple analytical dashboard in Power BI.

## 📅 Week 2 – Data Visualization Practice

**Objective:**

To explore advanced Power BI visualization tools and customization options.

**Process:**

Practiced building charts such as bar, line, pie, and card visuals; learned how to modify chart colors, backgrounds, and text; experimented with slicers, filters, and interactive dashboard layouts.

**Outcome:**

Developed a refined visualization .pbix file integrating multiple visuals on a single interactive dashboard, improving storytelling through data.

## 📅 Week 3 – Super Store Product Analysis

**Objective:**

To analyze Super Store sales performance and profitability across regions and categories.

**Process:**

Cleaned and transformed the dataset, created key visuals like bar, line, pie, donut, card, and treemap charts; customized dashboard design with slicers and filters for interactivity.

**Outcome:** 

Delivered an insightful dashboard highlighting sales fluctuations, profit margins, and customer segment performance, supporting real-time business evaluation.
